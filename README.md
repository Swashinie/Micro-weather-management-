# 🌦️ Microclimate Data Management System

A lightweight web application to record, store, and manage microclimate data such as temperature, humidity, and wind speed using manual data entry.

---

## 📌 Features

- Manual entry of microclimate data via a web form  
- Responsive user interface built with HTML, CSS, and JavaScript  
- Backend powered by PHP for data handling and validation  
- MySQL database for structured data storage  
- Animated UI using `particles.js` for enhanced UX

---
